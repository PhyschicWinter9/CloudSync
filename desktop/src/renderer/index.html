By category

Backup

Scan this machine, then copy everything into a versioned backup directory.

Export

Zip up the backup directory to share anywhere git isn't — a cloud drive folder (Dropbox/Drive/OneDrive/iCloud), email, or a USB stick.

Restore

Restore items from a backup directory back to their original locations.

Import a backup

Bring in a backup made elsewhere: a cloud (git) remote, or a .zip file from a cloud drive, email, or USB stick.

Chat sessions

Read a session transcript before you rely on it — verify it's actually the conversation you expect. Or export every chat as a readable file to browse or archive outside ClaudeSync.

Settings

MCP server configs and settings can contain API keys and tokens in plaintext. ClaudeSync backs them up faithfully so restores are exact — keep your backup destination private (a private git repository, not a public one).
